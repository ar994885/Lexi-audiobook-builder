Upload these three files to the root of a GitHub repository:

  render.yaml
  Dockerfile
  studio.zip

Then in Render: New -> Blueprint -> pick that repository -> Apply.
Render builds the image, starts the app, and gives you a URL.

Free instance: 0.1 CPU / 512 MB, sleeps after ~15 min idle, disk is temporary.
Convert a few chapters per build, and download the bundle straight away.
